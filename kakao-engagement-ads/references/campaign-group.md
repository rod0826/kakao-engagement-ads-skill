# 캠페인·광고그룹 등록

출처: [카카오 공식 가이드](https://kakaobusiness.gitbook.io/main/ad/moment/engagement/campaign-group). 확인일: 2026-10-07. 아래 수치는 이 날짜의 문서 기준이며 실제 등록 시 최신 문서와 화면을 대조한다.

## 목표·유형 결정

| 설정 | 방문 | 전환 |
|---|---|---|
| 용도 | 전환 데이터가 부족할 때 방문과 데이터 축적 | 수집한 데이터를 바탕으로 전환 가능 사용자 최적화 |
| 광고 유형 | 카카오 비즈보드 / 디스플레이 | 카카오 비즈보드 / 디스플레이 |
| 픽셀 & SDK | 필수 | 필수 |
| 입찰 | 자동(클릭수 최대화) 또는 수동 | 자동(전환수 최대화)만 가능 |
| 비용 목표(선택) | 자동입찰: CPC 목표 | 자동입찰: CPA 목표 |
| 수동 과금 | CPC 또는 CPM | 해당 없음 |
| 예상 모수 | 제공 | 제공하지 않음 |
| 게재 | 자동입찰은 시스템 운영; 수동은 화면 옵션 확인 | 빠른 게재만 가능 |

목표를 사용자의 실제 목적에 맞춰 선택한다. 전환 목표는 잠재고객 또는 서비스 신청 이벤트를 선택할 수 있다. 사전예약·상담신청 등은 잠재고객, 서비스가입·구독완료 등은 서비스 신청의 문서 예시다. 업종 예시만으로 사용자의 이벤트를 확정하지 않는다. 기존 픽셀 & SDK도 재사용 가능하며, 새 생성이 필요하면 [픽셀 & SDK 가이드](https://kakaobusiness.gitbook.io/main/tool/pixel-sdk/install)를 확인한다.

## 캠페인

광고계정에서 [광고 만들기] → [참여형 광고] → 목표·유형 → 픽셀 & SDK와 해당 전환 이벤트 → 예산·이름 → [광고그룹 만들기] 순서로 진행한다. 실제 화면에서 저장 시점과 운영 상태를 확인한다.

- 이름은 최대 50자.
- 캠페인 일예산은 VAT 포함, 설정 시 50,000~1,000,000,000원이고 10원 단위다. 미설정도 가능하지만 사용자 선택 없이 미설정으로 운영하지 않는다.
- 일예산은 엄격한 과금 상한이 아니다. 중단·집계 지연으로 초과 과금될 수 있고, 하위 그룹 예산 합이 캠페인 예산보다 크면 초과 폭이 커질 수 있다. 승인된 예산을 정확히 입력하고 이러한 특성을 예산 결정에 반영한다.
- 예산 변경의 반영에 환경에 따라 10분 이상 걸릴 수 있다. 값이 바로 바뀌지 않는다고 반복 변경하지 않는다.

## 광고그룹

기존 캠페인에는 해당 계정을 선택하고 캠페인에서 [+광고그룹 만들기]로 추가한다. [생성 한도](https://kakaobusiness.gitbook.io/main/ad/moment/intro/run/account-guide)는 필요한 경우 확인한다.

1. 맞춤타겟·데모그래픽을 설정한다. 상세 조건은 [타겟 관리](https://kakaobusiness.gitbook.io/main/ad/moment/intro/run/target)를 참조한다.
2. 게재지면·디바이스를 선택한다. PC는 디스플레이만 지원한다. 비즈보드의 [채팅탭에만 노출]은 카카오톡 필터이므로 다른 지면을 함께 선택하면 그 지면에도 노출된다.
3. 입찰을 설정한다. 수동은 CPC/CPM과 금액(1원 단위)을 입력한다. 방문 자동입찰은 실제 검증 화면에서 클릭수 최대화와 선택적 CPC 비용 목표를 제공했다. 전환 자동입찰의 전환수 최대화·CPA 목표와 구분한다. 현재 목표의 화면 옵션을 확인하며 비용 목표를 실제 결과 비용의 상한으로 설명하지 않는다.
4. 그룹 일예산(VAT 포함), 집행기간, 요일·시간을 입력한다. 그룹 예산 최소·최대는 이 문서에 명시되지 않았으므로 캠페인 한도를 대신 적용하지 않는다.
5. 시작일은 미래인 경우 수정 가능하며 그 외에는 종료일만 수정 가능하다. 시간 제한 소재는 필요한 심야 타게팅을 선택하며 생성 후 해제할 수 없는 조건을 확인한다.
6. 게재방식은 기본 빠른 게재다. 일반 게재는 시간대별 예산 분할에 쓰지만 전환 목표에는 적용할 수 없다. 자동입찰은 시스템이 운영하므로 노출된 옵션만 설정한다.
7. 우측 요약을 확인하고 이름을 입력한 뒤 [저장] 또는 [저장하고 소재 만들기]로 진행한다. [광고그룹 추가]는 추가 그룹을 실제로 요청했을 때 사용한다.

네트워크 지면은 문서상 URL·소식 랜딩 소재만 노출된다. 참여형 소재는 비즈니스폼+ 랜딩이므로 이를 네트워크 지원이라고 단정하지 말고 현재 화면의 조합 허용 여부·안내를 확인한다. 충돌하면 지원되는 조합을 설명하고 타겟이나 랜딩을 몰래 바꾸지 않는다.

## 2026-10-07 실제 등록 검증에서 확인한 UI

방문·디스플레이 조합을 Chrome에서 캠페인과 그룹 저장까지 실행했다. 그룹 일예산은 처음에 100,000원, 기간은 당일 시작·종료일 미설정으로 표시되었다. 이 기본값을 사용자 승인 설정으로 간주하지 않는다. 승인된 검증에서는 그룹 일예산 10,000원과 미래 시작일·종료일을 입력해 저장했다. 이 성공 값은 모든 입찰 유형의 최소 예산 규칙을 의미하지 않는다.

날짜 텍스트는 날짜 선택기를 여는 컨트롤이다. 시작일·종료일 각각 달력에서 연월과 일자를 선택하고 달력의 [저장]으로 적용한 뒤 요약의 기간을 대조한다. 달력 [저장]은 캠페인·그룹의 최종 등록 저장과 다르다. 종료일 미설정을 해제하면 초기 종료일이 자동 입력되므로 원하는 종료일로 바꾼다.

신규 생성 흐름에서 [광고그룹 만들기]는 그룹 설정으로 넘어갔고, [저장하고 소재 만들기] 후 소재 URL에 캠페인·그룹 ID가 표시되었다. 각 단계 전환만으로 독립적인 저장 완료를 추정하지 않는다. 캠페인 일예산 안내가 단계 전환과 최종 저장 때 표시되었다. 안내를 보고 실제 예산 합을 확인하며 자동 증액하지 않는다.
