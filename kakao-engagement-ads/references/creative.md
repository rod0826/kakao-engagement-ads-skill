# 소재 등록·비즈니스폼+ 연결

출처: [카카오 공식 소재 가이드](https://kakaobusiness.gitbook.io/main/ad/moment/engagement/content). 확인일: 2026-10-07. 규격과 심사 조건은 선택한 유형의 최신 문서를 확인한다.

## 새 소재 또는 기존 소재

새 그룹의 [저장하고 소재 만들기], 또는 계정 → 캠페인 → 그룹의 [소재 만들기]로 진입한다. 기존 소재는 [기존 소재]에서 캠페인/그룹 이름으로 검색한다. 불러오기 조건은 캠페인 유형·목표와 그룹의 디바이스·게재지면 일치다. 재사용 후에도 이 그룹에서의 랜딩·문구·미리보기를 확인한다.

새 소재는 유형에 맞는 필수 필드와 업로드 규격을 현재 화면에서 확인한다. 크기·용량·글자 수를 다른 유형에서 복사하지 않는다. 미제공 브랜드 자산을 임의의 로고나 실제 제품 이미지로 대체하지 않는다.

- 비즈보드: [소재 만들기](https://kakaobusiness.gitbook.io/main/ad/moment/performance/talkboard/content), [제작 규격](https://kakaobusiness.gitbook.io/main/ad/moment/performance/talkboard/content-guide).
- 디스플레이: [소재 만들기](https://kakaobusiness.gitbook.io/main/ad/moment/performance/displayad/content), [이미지·동영상 네이티브 제작 규격](https://kakaobusiness.gitbook.io/main/ad/moment/performance/displayad/content-guide).
- 공통: [소재 심사](https://kakaobusiness.gitbook.io/main/ad/moment/intro/ad-audit/ad-unit). AI 생성 소재는 [현재 AI 심사 안내](https://kakaobusiness.gitbook.io/main/ad/moment/intro/ad-audit/standards#ai)를 확인하며 적합성이나 승인을 보증하지 않는다.

## 폼 연결

참여형 소재의 [랜딩 URL 설정]은 비즈니스폼+로 지정된다. 일반 웹 URL 또는 구 비즈니스폼 연동으로 대체하지 않는다.

1. 기존 폼을 쓸지 신규 제작이 필요한지 확인한다. 이름이 비슷하면 폼 ID·내용·상태로 구분한다.
2. 가이드의 저장완료 폼 연결 조건과 현재 선택 가능 목록을 확인한다. 임시 저장 폼이 바로 연결 가능하다고 가정하지 않는다.
3. 새 폼은 [공식 제작 가이드](https://kakaobusiness.gitbook.io/main/ad/moment/engagement/bizformplus/new) 또는 설치된 폼 전용 스킬로 만든다. 최종 완료 권한·수집 목적·동의문 등 미확정 사항이 있으면 광고 소재 연결을 위해 임의로 최종화하지 않는다.
4. 지정된 폼을 선택하고 랜딩 미리보기에서 광고 약속과 폼의 행사·상품·정보 수집 목적이 일치하는지 확인한다. 확인을 위해 실제 참가자 응답을 제출할 필요는 없다.
5. 소재 이름과 요약을 확인하고 [설정완료]로 개별 소재 구성을 완료한다. 유형별 화면에 전체 [저장] 단계가 있으면 설정완료된 소재 탭을 대조한 뒤 [저장]까지 실행한다. [설정완료] 클릭만으로 서버 등록 완료를 단정하지 않는다. 목록/상세에서 소재와 폼 연결을 다시 확인한다.

폼이 목록에 없으면 계정·폼 상태·접근 권한과 검색 조건부터 확인한다. 버튼 비활성이나 선택 불가를 우회하거나 같은 폼을 반복 생성하지 않는다.

## 심사·집행 준비

문서는 소재를 영업일 기준 집행 2~3일 전에 등록하고, 집행 1일 전까지 최소 1개 소재가 승인되도록 준비할 것을 안내한다. 예상 심사 소요를 승인 보장으로 설명하지 않는다. 광고 주체와 정보 수집 주체가 다르면 [의견 및 증빙]의 증빙 첨부 권장사항을 확인한다. 첨부 문서를 임의로 만들지 않는다.

등록 후 심사 상태와 운영 상태를 각각 확인한다. 폼 운영·연결 캠페인 성과는 [폼 관리 가이드](https://kakaobusiness.gitbook.io/main/ad/moment/engagement/bizformplus/manage)를 참조한다. 보고서·응답 관리가 주된 요청이면 폼 전용 스킬로 연결한다.

## 2026-10-07 실제 소재·폼 연결 검증

방문·디스플레이, 이미지 네이티브, PC·모바일, 모든 지면 설정에서 계정 이미지 라이브러리의 기존 프로필 이미지와 1200×600 홍보 이미지를 선택해 등록했다. 새 파일 업로드·이미지 에디터는 이번 검증에 포함하지 않았다. 라이브러리에 표시되는 후보는 이미지 용도와 규격에 따라 달랐다.

화면 카운터는 타이틀 25자, 프로필 이름 20자, 홍보문구 45자, 소재 설명 30자, 소재 이름 40자였다. 현재 카운터를 우선하고 다른 소재 유형에 이 값을 일반화하지 않는다. 행동유도 버튼 [설문하기]를 선택했다.

[비즈니스폼+ 선택] 목록에는 이름·ID·수정일과 [미리보기]가 표시되었다. 임시저장 항목도 목록에 보였지만 연결 가능 여부는 시험하지 않았다. 기존 완료 테스트 폼의 미리보기는 별도 iframe에 열렸으며 시작 페이지와 폼 이름을 확인했다. 미리보기 [확인]으로 닫은 뒤 지정 폼을 선택했다. 미리보기 열기만으로 폼을 선택한 것으로 간주하지 않는다.

[설정완료] 후 우측 설정완료 소재 수가 1로 바뀌었고, 우측 전체 [저장] 후 대시보드에 소재가 생성되어 심사 중으로 표시되었다. 저장된 이름에는 업로드 규격 접미사가 붙었으므로 입력한 이름과 목록 이름이 완전히 같아야 한다고 요구하지 않는다.

저장 후 소재 썸네일의 미리보기에서 PC·모바일 랜딩 URL에 같은 폼 ID가 있는지 확인했다. 플랫폼이 표시하는 URL에 치환 매크로가 포함되어 있어도 이를 임의로 대체하거나 템플릿 URL을 실제 응답 제출 링크로 실행하지 않는다. 소재 미리보기의 연결 확인과 실제 참여자 응답 제출은 별개다.
