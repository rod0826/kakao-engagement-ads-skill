# 참여형 광고 등록

카카오모먼트에서 캠페인 → 광고그룹 → 비즈니스폼+ 연결 소재를 등록한다. 공식 가이드 확인일은 2026-10-07이다. 작업 시 현재 UI와 관련 공식 문서를 확인하고 달라진 제한·옵션을 적용한다. 문서에 없는 생성 API, 저장 상태, 버튼, 심사 결과를 추정하지 않는다.

## 필요한 자료 선택

- 캠페인·그룹 생성 및 설정 검토: [campaign-group.md](references/campaign-group.md).
- 새 소재 등록·기존 소재 재사용·폼 연결: [creative.md](references/creative.md).
- 저장 결과·심사 상태 확인 및 중단 복구: [verification.md](references/verification.md).
- 비즈니스폼+ 문항·동의문을 새로 만들어야 하면 설치된 `kakao-bizformplus` 스킬을 함께 사용한다. 없으면 [공식 폼 제작 가이드](https://kakaobusiness.gitbook.io/main/ad/moment/engagement/bizformplus/new)를 확인한다. 기존 폼 연결에는 별도 스킬 설치가 필요하지 않다. 전용 스킬 저장소는 https://github.com/rod0826/kakao-bizformplus-skill 이다.

## 범위와 입력값

이미 받은 정보와 열린 작업 탭에서 확인한 값을 사용하고, 작업을 막는 누락 정보만 질문한다. 같은 이름의 계정·캠페인·폼은 ID와 상위 경로로 구분한다.

필요한 입력은 대상 광고계정, 신규/기존 캠페인·그룹, 목적과 광고 유형, 픽셀 & SDK, 전환 이벤트(해당 시), 예산·입찰·기간·타겟·지면·디바이스, 소재 파일·문구, 연결할 폼, 원하는 완료 상태다. 기획만 요청하면 사이트를 변경하지 않고 설정안을 만든다. 미확정 예산·입찰·일정·폼을 임의로 채우지 않는다. 저장 없이 입력한 초안을 요청하면 편집 탭을 유지한다.

등록 요청은 필요한 저장·연결 작업에 대한 승인으로 취급한다. 이미 승인된 작업마다 재확인을 요구하지 않는다. 다만 실제 집행·기존 운영 광고의 예산 변경·충전·폼 작성 완료 등은 해당 작업의 요청 범위와 실행 환경 정책을 확인한다. 새 폼 작성 완료는 수정 가능 여부가 달라질 수 있으므로 폼 전용 절차를 따른다. 광고 등록이 즉시 노출이나 과금을 유발할 수 있는 화면이라면, 집행까지 승인되었는지 먼저 구분한다. 집행 승인이 없으면 제공되는 OFF/중지 옵션으로 등록하고, 그런 옵션이 없어 과금 없이 저장할 수 없으면 검토 가능한 입력을 끝낸 뒤 그 마지막 단계만 사용자에게 확인한다. 존재하지 않는 임시 저장 기능을 만들어 설명하지 않는다.

## 브라우저와 실행

사용자가 지정한 브라우저·탭을 우선하고, 지정이 없으면 Codex native Computer Use로 Chrome의 특정 탭을 제어한다. Aside 또는 ego-browser/ego lite는 사용자가 명시했을 때만 선택한다. 도구 문서를 읽고 URL·제목을 확인한 탭에 입력한다. Chrome 제어가 없으면 설정안·문구·가이드 확인을 진행하고 실제 등록을 위해 필요한 환경을 설명한다.

1. 계정·상위 경로와 기존 항목을 확인하고 중복 생성 가능성을 점검한다.
2. 요청 단계에 필요한 참고자료를 읽고 목표·유형·연동·입찰 등의 조합을 검토한다.
3. 캠페인·광고그룹·소재 순서로 필요한 단계만 입력한다. 기존 그룹에 소재만 추가하면 캠페인을 새로 만들지 않는다.
4. 저장·설정완료 직전 현재 요약, 비용·기간, 소재 미리보기와 폼을 대조한다. 승인된 범위의 저장을 실행한다.
5. 목록 또는 상세에서 실제 생성·연결 상태를 확인하고 결과를 보고한다. 클릭만 성공한 상태를 등록 완료라고 하지 않는다.

## 결과 보고

계정/캠페인/그룹/소재의 이름과 확인 가능한 ID, 연결 폼, 저장·심사·ON/OFF 상태, 예산·기간 등 주요 설정을 간단히 정리한다. 등록 완료·심사 승인·실제 노출은 각각 확인한 범위만 말한다. 기획 또는 미저장 초안이면 그 상태와 남은 작업을 명시한다. 공개 자료에는 인증정보·계정 식별정보·참가자 응답을 넣지 않는다.
