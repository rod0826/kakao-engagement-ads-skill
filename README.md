# 참여형 광고 등록 - Codex 스킬

카카오모먼트 참여형 광고의 **캠페인·광고그룹 등록**과 **비즈니스폼+ 연결 소재 등록**을 돕는 **Codex 전용 비공식 스킬**입니다. 호출 이름은 `$kakao-engagement-ads`입니다.

카카오 또는 OpenAI가 제작·인증한 공식 배포물이 아닙니다. 2026년 10월 7일 공식 가이드를 확인해 작업 지침을 작성했습니다. 최신 화면과 문서에 따라 제한·규격을 확인하도록 구성했습니다.

## 지원 범위

- 방문·전환 목표, 비즈보드·디스플레이 유형, 픽셀 & SDK 연동 설정.
- 캠페인 예산과 광고그룹 타겟·지면·디바이스·입찰·기간·게재방식 등록.
- 새 소재 등록과 기존 소재 재사용, 저장완료 비즈니스폼+ 선택·연결.
- 등록 결과와 폼 연결, 심사·운영 상태 확인 및 중단 후 복구.

[비즈니스폼+ 스킬](https://github.com/rod0826/kakao-bizformplus-skill)과 **별도 저장소**입니다. 폼 문항·동의문 제작과 응답·권한·알림·보고서 관리는 기존 전용 스킬이 담당합니다. 기존 폼을 광고소재에 연결하는 데는 그 스킬이 필수 의존성이 아닙니다.

## 설치

이 저장소의 `kakao-engagement-ads/` 폴더 전체를 `~/.codex/skills/`에 복사하세요. 사용자 지정 `CODEX_HOME`을 사용하면 그 경로의 `skills/`에 복사합니다. 같은 이름의 스킬이 있다면 내용을 비교하고 백업한 뒤 교체하세요. 새 Codex 대화에서 스킬 목록을 확인합니다.

또는 다음과 같이 설치를 요청하세요.

```text
$skill-installer https://github.com/rod0826/kakao-engagement-ads-skill 저장소의 kakao-engagement-ads 스킬을 설치해줘.
```

```text

```

```text
$kakao-engagement-ads Chrome의 지정 광고계정에 방문 목표·디스플레이 캠페인을 등록해줘. 아래 예산, 픽셀 & SDK, 타겟, 기간을 사용하고 광고 집행은 하지 마.
```

```text
$kakao-engagement-ads 기존 캠페인의 지정 광고그룹에 이 이미지와 문구로 소재를 추가해줘. 비즈니스폼+ ID는 아래와 같아. 등록과 연결 상태를 확인하고 집행은 하지 마.
```

계정·목표·유형·예산·일정·연동·타겟·소재·폼과 원하는 완료 상태를 전달하면 됩니다. 이미 전달한 정보는 반복해서 묻지 않도록 했습니다. 미확정 예산이나 집행 일정을 임의로 결정하지 않습니다.

## 실행 환경과 검증 범위

실제 등록에는 카카오모먼트 로그인·광고계정 권한과 Codex native Computer Use의 Chrome 제어가 필요합니다. 사용자 지정 브라우저·탭을 우선합니다. Chrome 제어가 없으면 기획과 설정 안내를 제공할 수 있습니다.

파일 구조·YAML·내부 참조를 검증했고, **2026년 10월 7일 Chrome에서 방문·디스플레이 캠페인·그룹·이미지 네이티브 소재 등록과 기존 완료 폼 연결을 실제 실행했습니다.** 저장 후 목록과 PC·모바일 랜딩의 폼 ID를 확인하고 생성한 세 항목을 모두 OFF로 설정했습니다. 심사 상태는 확인 당시 심사 중, 비용·노출수는 0이었습니다. 심사 승인·실제 집행·응답 제출과 다른 광고 조합은 검증하지 않았습니다. 등록 요청과 실제 집행 권한을 구분하며, 저장·심사 승인·노출을 각각 확인하도록 지침을 구성했습니다. 이 스킬은 광고비 상한이나 심사 통과를 보장하지 않습니다.

## 실제 등록 검증으로 보완한 지침

방문 자동입찰의 클릭수 최대화·CPC 목표를 전환 목표의 CPA 설정과 구분했습니다. 날짜 선택기의 [저장], 개별 소재의 [설정완료], 전체 소재의 [저장]을 각각 설명합니다. 생성 후 이름에 규격 접미사가 붙는 동작과 폼 미리보기 iframe, 저장 후 PC·모바일 랜딩 확인을 반영했습니다. 상태 열의 OFF/운영 불가와 ON/OFF 토글의 체크 상태가 다를 수 있어 실제 토글을 확인하도록 했습니다. 검증에 사용한 계정·픽셀·폼·광고 ID, 참가자 정보와 화면 캡처는 공개 배포물에 넣지 않았습니다.
